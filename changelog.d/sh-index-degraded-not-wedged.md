Fixed

- **A scripthash index fault no longer wedges the chain.** A `Corrupt` or I/O error from the SH index during a disconnect, or from a write-behind append, used to fail the block (`scripthash extent last page not ver=2`) and leave the node unable to disconnect or connect, with `RBITCOIN_SH_FORCE_REBUILD` unreachable below tip. The index is now marked degraded: blocks keep connecting and disconnecting with SH deferred, Electrum and Esplora address routes answer `scripthash index rebuilding` (503), and a background supervisor wipes the index and rebuilds it from Class A, then re-arms write-behind. A `store/scripthash.degraded` marker makes a restart wipe the broken index at open. `RBITCOIN_SH_FORCE_REBUILD` now also wipes at open, not only at tip entry. `RBITCOIN_SH_AUTO_REBUILD=0` leaves the index degraded until a restart. No schema change. The wipe also clears the ingest and sealed overflow heads, which a cold rebuild used to leave in place.
